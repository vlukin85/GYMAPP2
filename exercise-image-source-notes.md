|---|---|---|
| [Wger](https://github.com/wger-project/wger) | Открытый фитнес-проект с каталогом упражнений и изображениями. | Код имеет AGPL-3.0, но лицензия данных упражнений и иллюстраций определяется отдельно для каждого упражнения. Перед массовым импортом нужно проверить, что выбранные файлы действительно входят в репозиторий, а не являются внешними ссылками с отдельными условиями. |

## Подтверждённые детали free-exercise-db

- Лицензионный файл: <https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/LICENSE.md>. Он прямо разрешает копирование, изменение, публикацию, использование, продажу и распространение содержимого без ограничений по цели.
- Каталог данных: <https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/dist/exercises.json>. Каждая запись содержит поле `images` с путями наподобие `Air_Bike/0.jpg`.
- Базовый URL фотографий: `https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/exercises/<путь-из-images>`.

## Решение

Для текущего приложения сохраняется приоритет: пользовательские изображения → индивидуальные одобренные AI-иллюстрации → ранее созданные варианты → групповая иллюстрация. Открытые фото free-exercise-db подключаются как дополнительный вариант медиатеки с явной подписью источника, без разрушительной замены пользовательских медиа.
