# Расчёты параметров тела и калорий

## ИМТ

ИМТ рассчитывается как вес в килограммах, делённый на квадрат роста в метрах. Для взрослых NHLBI приводит диапазоны: ниже 18,5; 18,5–24,9; 25,0–29,9; 30 и выше. В приложении это информационный показатель, а не медицинская диагностика.

Источник: [NHLBI — Calculate Your BMI](https://www.nhlbi.nih.gov/calculate-your-bmi).

## Ориентир калорийности

Базовый обмен оценивается по Mifflin–St Jeor: для мужчин `10×вес + 6,25×рост − 5×возраст + 5`, для женщин `10×вес + 6,25×рост − 5×возраст − 161`. Это оценка энергозатрат в покое для здоровых взрослых; приложение показывает её как отправную точку, не как персональное медицинское назначение.

Источник: [Mifflin et al., 1990, PubMed](https://pubmed.ncbi.nlm.nih.gov/2305711/).
