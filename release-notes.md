# Дневник тренировок — 1.0.4

В этой версии приложение получило редизайн Dark Energy: тёмная фирменная тема стала оформлением по умолчанию, а остальные варианты дизайна переключаются в настройках. Фотографии появились у всех упражнений каталога, управление тренировкой вынесено на часы, а видео упражнений теперь открываются на RuTube вместо YouTube. Каталог продуктов вырос до 334 позиций с миниатюрами в едином стиле, главный экран настраивается через редактор виджетов статистики. Из исправлений: надёжное предпрослушивание сигнала завершения отдыха в настройках и полноэкранная заставка, которая показывает логотип целиком без обрезки. Логотип IronRise также добавлен в раздел «О приложении», адаптивная иконка Android приведена к маскам лаунчеров.

# Дневник тренировок — 1.0.2

В этой версии логотип обновлён для системной иконки Android. Интерфейс приложения сохраняет прежнее оформление; также доступны ручная загрузка изображений упражнений и обложек программ, выбор из ранее созданных иллюстраций и однократное окно «Что нового» после обновления APK.
