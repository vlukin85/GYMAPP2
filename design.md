# Дизайн приложения «Дневник тренировок»

## Направление интерфейса

Приложение рассчитано на Android-смартфон в портретной ориентации 9:16 и управление одной рукой. Визуальная система следует современным паттернам Apple Human Interface Guidelines: ясная иерархия, крупные заголовки, карточки с мягкими радиусами, нижняя таб-навигация, контекстные действия через листы и заметная, но экономная цветовая акцентность.

Бренд строится вокруг идеи «сильная привычка»: тёмный графитовый фон, тёплый лаймовый акцент и оранжевые маркеры прогресса. Основные данные всегда отображаются крупно: длительность, вес, повторы и рекорды.

## Список экранов

### 1. Сегодня

Домашний экран с приветствием, текущей датой и карточкой ближайшей тренировки. Показывает план на сегодня, число упражнений, ожидаемую длительность и кнопку «Начать тренировку». Ниже — мини-итоги недели: количество тренировок, общий объём и серия активных дней.

### 2. Каталог упражнений

Раздел с поиском, горизонтальными фильтрами групп мышц и сеткой/списком упражнений. Категории: грудь, спина, ноги, плечи, руки, корпус, кардио и всё тело. Каждая карточка содержит индивидуальную иллюстрацию, название, тип оборудования и целевую группу.

### 3. Детали упражнения

Экран с крупной hero-картинкой, названием, группой мышц, оборудованием, кратким описанием техники, кнопкой запуска видео-варианта выполнения и действием «Добавить в программу». В нижней части — личный рекорд пользователя и история лучших подходов.

### 4. Программы

Список сохранённых программ тренировок с количеством упражнений, длительностью и последним выполнением. Действия: создать программу, открыть программу, дублировать и запланировать в календарь.

### 5. Редактор программы

Форма с названием программы и списком упражнений. Для каждого упражнения редактируются плановые подходы, повторения, вес и интервал отдыха. Упражнения добавляются через поиск каталога; порядок меняется кнопками вверх/вниз. Внизу закреплена кнопка сохранения.

### 6. Активная тренировка

Пошаговый журнал тренировки. В верхней панели — прошедшее время и прогресс упражнений. Для каждого упражнения отображаются план и фактические поля веса/повторов по подходам, кнопка завершения подхода, счётчик отдыха и переход к следующему упражнению. После завершения показывается итоговая длительность и общий объём.

### 7. Календарь

Месячный календарь с точками запланированных и завершённых тренировок. Выбор дня открывает список программ на эту дату и позволяет добавить программу. Запланированная тренировка запускается одним нажатием.

### 8. Статистика

Раздел с карточками рекордов по упражнениям, личными максимумами веса и лучшими объёмами. Вверху — сводка за неделю/месяц: тренировки, минуты и общий тоннаж. Фильтр по группе мышц и периодам.

### 9. Настройки

Локальные настройки: единицы измерения (кг/фунты), длительность отдыха по умолчанию, тема оформления и управление демонстрационными данными. Авторизация и облачная синхронизация не входят в текущий объём.

## Основные пользовательские потоки

1. Пользователь открывает «Сегодня» → видит тренировку дня → нажимает «Начать тренировку» → отмечает фактические вес и повторы каждого подхода → завершает тренировку → получает итоговую длительность и обновлённый рекорд.
2. Пользователь открывает «Каталог» → выбирает группу мышц → открывает упражнение → смотрит технику/видео → нажимает «Добавить в программу» → выбирает существующую программу или создаёт новую.
3. Пользователь открывает «Программы» → нажимает «Создать» → добавляет упражнения → задаёт плановые подходы, вес, повторы и отдых → сохраняет программу → назначает её на дату в календаре.
4. Пользователь открывает «Календарь» → выбирает дату → добавляет программу → в день тренировки запускает её из календаря.
5. Пользователь открывает «Статистика» → выбирает период или группу мышц → просматривает рекорды и объём прогресса по упражнениям.

|---|---|---|
| Фон | `#101412` | Основной тёмный фон приложения |
| Поверхность | `#1A211D` | Карточки и нижние панели |
| Поверхность 2 | `#222B25` | Поля ввода и выделенные блоки |
| Основной текст | `#F4F7F2` | Заголовки и ключевые значения |
| Вторичный текст | `#A8B3AA` | Подписи и пояснения |
| Лаймовый акцент | `#C8F169` | Главные кнопки, активные табы, прогресс |
| Оранжевый прогресс | `#FF9F43` | Объём, рекорды и показатели нагрузки |
| Успех | `#7BE495` | Завершённые подходы и тренировки |
| Разделитель | `#303A33` | Бордеры и тонкие линии |

Кнопки имеют радиус 16 px, карточки — 20 px, поля — 14 px. Нижняя навигация содержит четыре раздела: «Сегодня», «Упражнения», «Программы», «Статистика»; календарь доступен через компактное действие в шапке и из программ.
