# Источники для базы питания

Локальная база калорийности использует усреднённые значения на **100 г съедобной части продукта**. При создании набора сверялись открытые справочные источники: [USDA FoodData Central](https://fdc.nal.usda.gov/) — официальный набор данных USDA о пищевой композиции, распространяемый по лицензии CC0, и каталог [FAO/INFOODS для России](https://www.fao.org/infoods/infoods/tables-and-databases/russia/en/), указывающий на российские таблицы химического состава и пищевой ценности продуктов.

Конкретная калорийность готовых блюд и брендовых продуктов может отличаться из-за рецептуры; экран дневника должен показывать, что это справочное значение, а пользователь указывает фактический вес порции.
