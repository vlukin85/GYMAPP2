# IronRise Watch Companion — ArkTS prototype

Нативный прототип companion-пульта IronRise для HarmonyOS wearable. Интерфейс повторяет утверждённый дизайн Expo-прототипа и предназначен для последующей проверки на Huawei Watch GT 6.

## Что реализовано

Главный экран `entry/src/main/ets/pages/Index.ets` содержит четыре состояния: ожидание, активный подход, отдых и синхронизация. Кнопка действия меняется по состоянию: `СТАРТ`, `ЗАВЕРШИТЬ`, `ПРОПУСТИТЬ` и `ПРОДОЛЖИТЬ`. Экран выполнен в формате компактного круглого watch-face с крупной основной кнопкой, тёмным фоном IronRise и красно-оранжевым акцентом таймера отдыха.

Пока это локальный UI-прототип без Bluetooth/Huawei Health/AppGallery API. Значения упражнения и таймера демонстрационные и должны быть заменены контрактом синхронизации с Android-приложением.

## Открытие в DevEco Studio

Откройте каталог `harmonyos-watch-companion` как отдельный проект в DevEco Studio с поддержкой HarmonyOS wearable. Установите зависимости OHPM, выберите wearable target, настройте signing profile и запустите debug build на совместимом эмуляторе или зарегистрированном устройстве.

Локальная среда Manus не содержит DevEco Studio, `hvigorw`, `ohpm` или `hdc`, поэтому здесь невозможно подтвердить фактическую сборку HAP и установку на часы. Структура проекта подготовлена для дальнейшего открытия в официальном DevEco окружении.

## Следующий этап

После запуска UI на устройстве нужно заменить локальные переходы `primaryAction()` на transport layer companion-связки: получить активную тренировку, отправлять `startSet`, `finishSet`, `skipRest`, принимать подтверждения и синхронизировать состояние с телефоном. Доступ к пульсу, калориям, фоновому таймеру и вибрации следует добавлять только после проверки API/permissions конкретной модели и региона GT 6.
